## ⭐ Featured Project

# SchengenStay

### Browser-based Schengen **90/180-day Calculator** and **Travel Planner**

SchengenStay is a **publicly deployed web application** that helps users:

- track travel history
- calculate remaining short-stay allowance
- identify potential violations
- plan future trips

🔗 **Live Application:** [mr-egr.github.io/SchengenStay](https://mr-egr.github.io/SchengenStay/)  
💻 **Source Code:** [github.com/Mr-Egr/SchengenStay](https://github.com/Mr-Egr/SchengenStay)

---

## 🛠 Engineering Highlights

- **Python architecture** — modular calculation engine with date validation, rolling-window algorithms, compliance checks, and trip planning  
- **Browser integration** — Python running in the browser through **Pyodide** and **WebAssembly**, connected to a JavaScript frontend  
- **Testing & quality** — automated tests with **pytest** and **Hypothesis**, browser integration tests, and cross-runtime verification  
- **CI/CD** — automated checks on **Windows** and **Ubuntu** with **GitHub Actions**, plus deployment via **GitHub Pages**  
- **User experience** — responsive UI, **English/Russian localization**, theme support, and local-first privacy approach
